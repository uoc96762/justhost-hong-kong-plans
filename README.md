## 免备案免掉的是什么，没免掉什么

免的是 ICP 备案。工信部规定只有部署在中国大陆境内节点的网站才必须备案，香港属于境外节点，域名解析过去不需要备案，开通后直接绑定域名访问。阿里云开发者社区的说法同样明确：香港服务器不需要备案，日本、新加坡、美国这些国外地区也都不需要。域名只拿来收邮件、不做网站的，国内外空间都不用备案。

大陆备案通常要等 7–20 个工作日，这是免备案真正省下的东西：时间，不是责任。

内容监管一条都没少。这类商家的服务条款普遍写明必须遵守中国及香港地区法律法规，禁止存储和传播违法违规内容。条款具体措辞各家不同，但方向一致：免备案不等于想放什么放什么，侵权、攻击、违规内容放到哪个机房都会被停。

## 线路才是便宜要还的那笔账

香港机房到大陆的物理距离近，配上 CN2 GIA 这类电信精品承载网（AS4809），国内主要城市 ping 通常在 10–40ms，体感接近国内服务器。对比美西机房 130ms 以上、日本机房 60–120ms，差距是能感觉出来的。

但"CN2"三个字在宣传页上被用得很随意。CN2 GIA 是全程独立通道，晚高峰基本不掉速，价格最贵；CN2 GT 只有国际段走 CN2，国内段可能切回 163 骨干网，高峰期会拥堵；BGP 优化是多线自动选路，电信联通移动都接，单家极致速度不如纯 GIA；国际 BGP 走国际出口，对海外用户友好，国内访问就慢一档。

JustHost 页面标的是 300Mbit 到 1000Mbit 的端口和不限流量，这是国际带宽的口径。端口大、流量不限，说明它给的资源充裕；但大陆访问快不快，取决于你选的那个机房接的是哪家上游。这两件事不能互相替代。
